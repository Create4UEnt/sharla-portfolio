# Sharla Brown — Portfolio

Professional portfolio website for Sharla Brown, creative producer and coordinator.

Built as a single self-contained HTML file — no build step, no framework, no external assets. Just open `index.html`.

## Stack

- Plain HTML, CSS, and vanilla JS
- Google Fonts: Anton, Inter, JetBrains Mono
- No build tooling, no dependencies

## Run locally

```bash
# any static server works; here are a few options:
python3 -m http.server 8080
# then open http://localhost:8080
```

Or just `open index.html` in your browser.

## Deploy

Hosted on GitHub Pages from the `main` branch root:
https://Create4UEnt.github.io/sharla-portfolio/
